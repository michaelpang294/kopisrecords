# Side A 2026 photos

Add your own photos in this folder. JPG, JPEG, PNG and WEBP (including uppercase extensions) work. Filenames must match the names below, followed by the extension. Missing photos are hidden automatically; the listing has a styled title card until cover is added.

| Filename | Placement |
| --- | --- |
| cover.jpg | Blog listing and top of article |
| booth-1.jpg | After the opening thank-you |
| crowd-1.jpg | First gallery photo in New faces |
| records-1.jpg | Second gallery photo |
| friends-1.jpg | Third gallery photo |

Use any subset of these photos. For more photos or to move them, edit the Side A entry in src/blog/posts.ts. Change gallery arrays or image names there. Update galleryAlt/imageAlt/coverAlt to describe your actual photos. Single images preserve their proportions; gallery thumbnails are square crops. No event photos are included in this patch.

The welcome post keeps its separate photos in ../welcome/.
